# Security Findings

This file is the human-readable triage record. Automated findings are reported in GitHub Code
Scanning and by workflow artifacts.

## Initial Baseline

The baseline is established only after compatible scanners have produced actual results.
The committed `security/baseline.json` is currently the source of accepted finding fingerprints.
